# 출력일보 → 출퇴근표 채우기

현장 **출력일보(서명지)** 사진과 **19:00 안전모 사진**을 근거로, 그달 엑셀 양식
`출입기록 기반 출퇴근표` 시트의 그날 줄(번호 · 퇴근 · 기본급 · O/T · 비고)을 채운다.

```
사진(출력일보 · 안전모)  ──Claude 가 읽음──▶  기록/날짜.csv  ──fill_ot.py──▶  결과 xlsx
                                              (사람이 확인하는 곳)
```

사진을 읽는 건 Claude, 엑셀에 쓰는 건 스크립트. 둘 사이의 **기록 CSV 가 확인 지점**이다 — 틀린 게 있으면 CSV 를 고치고 다시 돌린다.

## 하루 작업 순서

1. **자료 주기**: 출력일보 사진(+ 19:00 안전모 사진), 이번 달 양식 xlsx 를 Claude 에게.
2. **기록 CSV**: Claude 가 `기록/YYYY-MM-DD.csv` 를 만든다 — 출력일보에 인쇄된 순서대로 한 줄씩.
   ```
   번호,이름,소속,구분,퇴근,근거
   소장,이윤호,삼영,연장,,출력일보 주간·연장 서명
   3,안상용,삼언,주간,17:23,출력일보 주간 서명 · 연장칸 ✓
   ```
   - 이름은 **출력일보에 인쇄된 이름**(손글씨 · 안전모 이름표보다 정확).
   - `퇴근` 비우면 구분의 기본값(연장 = 19:00). 주간은 출입기록 퇴근 시간을 사용자가 알려 준다.
3. **채우기** (이 폴더에서):
   ```
   python3 fill_ot.py <양식.xlsx> 기록/2026-11-19.csv -o 결과/출퇴근표_2026-11-19.xlsx
   ```
4. **보고 확인**: `[양식에 없음]` `[고친 이름]` `[확인 필요]` `[건너뜀]` 을 읽는다.
5. **엑셀로 열기**: 수식(합계 · 집계표)은 열 때 다시 계산된다.
6. **저장소에 남기기**: 기록 CSV + 아래 '작업 기록' 한 줄. 양식 · 결과 xlsx 는 올리지 않음(생년월일 등 — `.gitignore`).

## 출력일보 읽는 규칙

| 출력일보 | 구분 | 채우는 값 |
|---|---|---|
| 주간 · 연장 둘 다 서명 | `연장` | 퇴근 19:00 · 기본급 1 · O/T 0.5 · 비고 연장 · 번호 = 앞 번호 + 1 |
| 주간 서명, 연장칸 ✓ | `주간` | 퇴근(출입기록) · 기본급 1 |
| 연차 | `연차` | 비고 연차 |
| 조출 / 야간 / 철야 | 같은 이름 | 기본급 1 · O/T 0.5 / 1 / 1 · 번호 매김 |

- 연장칸 ✓ = **연장 안 함** (사용자 확인, 2026-11-20).
- 19:00 안전모 사진 = 연장 근거(보조). 이름은 출력일보 명단으로 맞춘다.

## 틀린 것 고치기

| 상황 | 방법 |
|---|---|
| **아직 결과를 손대지 않았다** (권장) | 기록 CSV 를 고치고 **원본 양식에서 다시** 돌린다. 결과 파일을 새로 만든다. |
| 결과 파일에 다른 날·손입력이 이미 쌓였다 | 고칠 사람만 적은 작은 CSV(`이름,구분,퇴근`, 파일 이름은 날짜)로 결과 파일에 `--force`. 그 사람 그날 줄의 번호 · 퇴근 · 기본급 · O/T · 비고를 새 값으로 바꾸고, 새 구분에 없는 칸은 비운다(연장→주간이면 O/T · 비고 · 번호가 지워짐). 출근 칸은 건드리지 않는다. |
| 이름이 잘못 읽혔다 | CSV 의 이름을 고친다. 스크립트는 한 글자 차이만 스스로 고친다. |
| 그날을 통째로 잘못 넣었다 | 원본 양식에서 다시(위 첫 줄). 이전 날까지 반영된 파일이 원본이면 그걸 기준으로. |

`--force` 없이 같은 날을 다시 돌리면 이미 값 있는 사람은 **건너뛰고** 알린다 — 실수로 덮어쓰지 않는다.

## 한계 (스크립트가 못 하는 것)

1. **사진을 직접 읽지 않는다.** 출력일보 · 안전모 사진은 Claude 가 읽어 CSV 로 옮긴다. 손글씨가 흐리면 틀릴 수 있으니 CSV 를 한 번 보고 돌린다.
2. **양식 명단(AA열)에 있는 사람만** 채운다. 새 사람은 양식에 이름 칸 묶음(`=AA…`)을 먼저 만들어야 한다 — 없으면 `[양식에 없음]`.
3. **동명이인** 구분 못 함 — 같은 이름이 두 번 오면 두 번째는 건너뛴다.
4. **주말 · 공휴일 공수(1.5 / 2.25 / 3)는 안 채움.** 주말이면 경고만. 공휴일은 날짜로 알 수 없으니 직접 확인.
5. **번호(OT 일수)는 앞날까지만 보고** 매긴다. 이미 뒤 날짜에 번호가 있는데 앞날을 고치면 `[확인 필요] 뒤 날짜 번호를 다시 매겨야 함` — 뒤 번호는 손으로.
6. **주간 퇴근 시간**은 출입기록에서 알려 줘야 한다(사진에 없음).
7. **다른 시트(잔업OT 공수 일지 등)는 건드리지 않는다.** 그 시트들은 수식으로 따라온다. 수식은 엑셀에서 열 때 다시 계산되고, LibreOffice 는 '모두 다시 계산'이 필요할 수 있다.
8. **양식 모양이 바뀌면**(사람 칸 묶음이 C · O 열이 아니거나, 날짜 열 위치가 다르면) 멈추거나 못 찾는다고 알린다 — 스크립트를 고쳐야 한다.

## 스크립트가 지키는 것

- 이름: 같은 이름 우선, 글자 수 같고 **한 글자만** 다르면 고쳐 쓰고 알림(박구태→박규태). 더 느슨하면 다른 사람에 붙는다(박규태↛박태원 — 실제로 겪은 실수).
- 양식 보존: 엑셀 XML 의 해당 셀 값만 바꾼다(서식 · 그림 · 숨김 시트 · 수식 유지). 서식은 앞날 줄에서.
- 위치 찾기: 시트의 `=AA15` 같은 이름 칸으로 사람별 칸 묶음과 날짜 줄을 찾는다 — 명단이 늘어도 동작.

필요: Python 3.9+, `openpyxl`, `lxml`.
