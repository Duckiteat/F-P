# 출력일보 → 출퇴근표 채우기

현장 **출력일보(서명지)** 사진과 **19:00 안전모 사진**을 근거로, 엑셀 양식
`출입기록 기반 출퇴근표` 시트의 그날 줄(퇴근 · 기본급 · O/T · 비고 · 번호)을 채운다.

## 하루 일하는 순서

1. **사진 올리기**: 출력일보 사진(+ 19:00 안전모 사진)과 이번 달 양식 xlsx 를 Claude 에게 준다.
2. **기록 CSV 만들기**: `기록/YYYY-MM-DD.csv` — 출력일보의 인쇄된 이름 순서대로 한 줄씩.
   ```
   번호,이름,소속,구분,퇴근,근거
   소장,이윤호,삼영,연장,,출력일보 주간·연장 서명
   3,안상용,삼언,주간,,출력일보 주간 서명 · 연장칸 ✓
   ```
   - 이름은 **출력일보에 인쇄된 이름**을 쓴다(손글씨·안전모 이름표보다 정확).
   - `퇴근` 을 비우면 구분의 기본값(연장 = 19:00).
3. **채우기**:
   ```
   python3 fill_ot.py <양식.xlsx> 기록/2026-11-19.csv -o <결과.xlsx>
   ```
4. **보고 읽기**: `[양식에 없음]` `[고친 이름]` `[확인 필요]` 를 확인하고 결과 xlsx 를 엑셀로 연다(수식은 열 때 다시 계산됨).
5. **커밋**: 기록 CSV 와 아래 '작업 기록' 한 줄. 양식·결과 xlsx 는 올리지 않는다(생년월일 등 개인정보 — `.gitignore`).

## 읽는 규칙 (출력일보)

| 출력일보 | 구분 | 채우는 값 |
|---|---|---|
| 주간·연장 둘 다 서명 | `연장` | 퇴근 19:00 · 기본급 1 · O/T 0.5 · 비고 연장 · 번호 = 앞 번호 + 1 |
| 주간 서명, 연장칸 ✓ | `주간` | 기본급 1 (퇴근 시간은 출입기록에서 손으로) |
| 연차 | `연차` | 비고 연차 |
| 조출 / 야간 / 철야 | 같은 이름 | O/T 0.5 / 1 / 1 · 번호 매김 |

- 연장칸 ✓ 를 '연장 아님'으로 읽는 근거: 같은 사람들(삼언)이 앞날(11/18) 양식에서 17:2x 퇴근 · OT 없음.
- 주말·공휴일(주말주간 1.5, 주말연장 2.25, 주말야간·철야 3)은 스크립트가 채우지 않는다 — `[확인 필요]` 로 알림.

## 스크립트가 지키는 것

- **이름 맞추기**: 같은 이름 우선. 글자 수가 같고 **한 글자만** 다르면 고쳐 쓰고 알린다(박구태→박규태). 더 느슨하게 하면 다른 사람에게 붙는다(박규태↛박태원 — 실제로 겪은 실수).
- **덮어쓰지 않음**: 이미 값이 있는 칸이면 그 사람은 건너뛰고 알린다(`--force` 로 덮어씀). 같은 날을 두 번 돌려도 안전.
- **양식 보존**: 엑셀 XML 의 해당 셀 값만 바꾼다(서식·그림·숨김 시트·수식 유지). 서식은 앞날 줄에서 가져온다.
- **양식 위치 찾기**: 시트에서 `=AA15` 같은 이름 칸을 찾아 사람별 칸 묶음과 날짜 줄을 찾는다 — 명단(AA열)이 늘어도 그대로 동작.

필요: Python 3.9+, `openpyxl`, `lxml`.
