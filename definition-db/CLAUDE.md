# 정의 데이터베이스에 저장하는 AI 에이전트를 위한 규칙

저장소는 `data/db.json`, 병합 기록은 `data/patches/`. 데이터는 사람이 아니라 AI가 넣는다.
`data/db.json` 을 직접 편집하지 말고 항상 패치 → 병합 경로를 쓴다 (명령은 이 폴더에서 실행).

1. `node dbtool.mjs status` 로 현재 규모를, `node dbtool.mjs prompt` 로 작성 규칙과 정의항 색인을 읽는다.
2. 연결할 개념의 뜻이 헷갈리면 `node dbtool.mjs context <피정의항>` 으로 각 정의항의 맥락을 확인하고 맞는 정의항 id 를 고른다.
3. 패치 JSON 을 임시 파일(저장소 밖, 예: 스크래치 폴더)에 쓰고 `node dbtool.mjs merge <patch.json> --dry` 로 확인한다.
   오류는 반드시 고치고, 새 경고(맥락 없음, 근거 구절 없음, 뜻 미지정)도 없앤다. 근거 구절이 정의 문장에 없는 연결은 지어내지 말고 빼거나, 정의 문장을 고친다.
4. 문제가 없으면 `--dry` 없이 병합한다 → `data/db.json` 갱신 + `data/patches/` 에 기록. 둘 다 커밋한다.

연결은 항상 피정의항이 아니라 정의항 id(`단백질#1`)로 걸고, `span` 에는 정의 문장 속 근거 구절을 원문 그대로 적는다.
기존 정의항을 수정하는 패치는 그 정의항 전체를 교체하므로 기존 연결·예시도 빠짐없이 다시 적는다.
