# 정의 데이터베이스에 저장하는 AI 에이전트를 위한 규칙

이 폴더의 데이터는 사람이 아니라 AI가 넣는다. 데이터베이스 JSON 을 직접 편집하지 말고 항상 패치 → 병합 경로를 쓴다.

1. `node dbtool.mjs prompt <db.json>` 으로 작성 규칙과 현재 정의항 색인을 읽는다.
2. 연결할 개념의 뜻이 헷갈리면 `node dbtool.mjs context <db.json> <피정의항>` 으로 각 정의항의 맥락을 확인한 뒤 맞는 정의항 id 를 고른다.
3. 패치 JSON 을 임시 파일에 쓰고 `node dbtool.mjs merge <db.json> <patch.json> --dry` 로 확인한다.
   오류는 반드시 고치고, 새로 생긴 경고(맥락 없음, 근거 구절 없음, 뜻 미지정)도 가능한 한 없앤다.
4. 문제가 없으면 `--dry` 없이 병합한다.

연결은 항상 피정의항이 아니라 정의항 id(`단백질#1`)로 걸고, `span` 에는 정의 문장 속 근거 구절을 원문 그대로 적는다.
